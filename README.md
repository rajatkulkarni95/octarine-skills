# Octarine Skills

Agent skills for working with [Octarine](https://octarine.app).

## Skills

- `octarine-notes`: Create, edit, and organize Markdown notes in an Octarine workspace.

## Install

After this repository is published to GitHub, install with `skills.sh`:

```sh
npx skills add rajatkulkarni95/octarine-skills --skill octarine-notes
```

To list the available skills first:

```sh
npx skills add rajatkulkarni95/octarine-skills --list
```
